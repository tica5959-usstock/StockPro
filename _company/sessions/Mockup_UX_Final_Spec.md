# 💡 Mock-up 최종 UI/UX 디자인 스펙 시트: 전력 손실 회피 시뮬레이터

**[프로젝트 목표]**
*   **목표:** 사용자가 '전력/열 관리가 실패했을 때 발생하는 비용적 손실액'을 직접 조작하고 체감하게 하여, 분산형 시스템(DER)의 경제적 가치와 투자 필요성을 강력히 인지시키는 인터랙티브 경험 제공.
*   **핵심 원칙:** Pain $\to$ Analysis $\to$ Solution (상태 기반, 점진적 공개). 모든 전환은 사용자 의사결정 유도에 초점을 맞춤.

---

## 📐 I. 전체 구조 및 플로우맵 (User Journey Map)

| 단계 (State) | 사용자 경험/목표 | 주요 액션 (Trigger) | 시각적 핵심 요소 | 목표 결과 (Outcome) |
| :--- | :--- | :--- | :--- | :--- |
| **1. Pain Point 인식** (문제 제기) | 현재 시스템의 취약성 인지 및 손실액 체감. (감정적 충격 유도) | 스크롤 다운, '손실 현황 보기' 버튼 클릭 | 대형 타이포그래피 + 깜빡이는 경고/데이터 시각화 (빨간색 계열) | **"당신이 지금 모르는 비용적 손실액은 얼마일까요?"**라는 질문으로 몰입 유도. |
| **2. Analysis (분석)** (대안 제시) | 문제 해결의 가능성 탐색 및 기술적 비교 체험. (지적 호기심 자극) | 슬라이더/토글 조작, 데이터 포인트 클릭 | 비교 차트(Dual Axis), 인터랙티브 시뮬레이션 컴포넌트 | **"분산형 시스템은 이 문제를 이렇게 해결합니다."**라는 논리적 구조 제시. |
| **3. Solution (해결)** (투자 의사결정) | 경제적 가치 정량화 및 최종 투자 결정 유도. (안도감/기회 포착감 부여) | ROI 계산 버튼 클릭, '다음 단계로 이동' CTA | 핵심 재무 지표 요약(KPI), 계좌 잔고 변화 애니메이션 (녹색 계열) | **"이 기술에 투자하면 이만큼의 수익을 확보할 수 있습니다."**라는 명확한 액션 플랜 제공. |

## ✨ II. 컴포넌트별 상세 비주얼 브리프 및 상호작용 로직

### 🟡 State 1: Pain Point 인식 (The Crisis)
*   **배경/톤:** 어둡고 경각심을 주는 무거운 톤. (Deep Charcoal Grey / Dark Navy).
*   **핵심 컴포넌트:** **'열 관리 실패 손실 시뮬레이터 (Failure Loss Meter)'**
    *   **시작 상태:** 배경에 주기적으로 빨간색 노이즈(Glitch effect)가 흐르며 불안감을 조성.
    *   **상호작용:** 사용자가 '데이터 센터 운영 비용' 등 기본 파라미터를 입력하면, 실시간으로 **손실액 누적 그래프 (Loss Accumulation Graph)**가 붉은 색조로 상승하는 애니메이션을 보여줘야 함.
    *   **애니메이션 로직:** 손실액이 특정 임계점을 넘을 때마다 경고음과 함께 화면 전체에 붉은 오버레이 필터(Overlay Filter)가 잠시 적용되어 충격을 극대화합니다.

### 🔵 State 2: Analysis (The Comparison)
*   **배경/톤:** 차분하고 논리적인 느낌의 밝은 배경으로 전환. (Off-White / Light Sky Blue).
*   **핵심 컴포넌트:** **'효율성 비교 시뮬레이터 (Efficiency Slider)'**
    *   **기능:** 중앙에 가상의 전력망 라인을 배치하고, 사용자가 슬라이더를 조작하여 '중앙집중식 vs 분산형'을 선택하게 합니다.
    *   **상호작용 A (슬라이더):** 슬라이더가 이동함에 따라 양쪽의 전력 손실 그래프(파란색/녹색)의 굵기와 높이가 실시간으로 변합니다. **손실액 차이($ Loss Gap)**를 명확히 시각화하는 것이 목적입니다.
    *   **상호작용 B (토글):** 'Cooling System' 토글을 ON/OFF 할 때, OPEX 항목의 재무 수치(원)가 애니메이션과 함께 급격히 변화하며 절감되는 효과를 보여줍니다.

### 🟢 State 3: Solution (The ROI Promise)
*   **배경/톤:** 신뢰성과 성공을 상징하는 밝고 개방적인 톤. (Bright White / Electric Green 강조).
*   **핵심 컴포넌트:** **'투자 수익 계산기 (ROI Calculator)'**
    *   **상호작용:** 사용자가 '예상 절감률(%)' 슬라이더를 조절하면, 현재까지의 누적 손실액($ Pain)과 비교하여 투자 후 확보 가능한 미래 현금흐름(Cash Flow) 그래프가 **녹색으로 폭발적으로 상승하는 애니메이션**을 보여줍니다.
    *   **KPI 시각화:** 최종 결과는 다음 3가지 지표로 요약되어야 하며, 숫자가 크고 명확해야 합니다:
        1.  총 투자 비용 (CAPEX)
        2.  예상 OPEX 절감액 (연간 $ Loss Avoided Amount)
        3.  순현재가치(NPV): *손실 회피로 인한 경제적 가치*

## 🎨 III. 디자인 시스템 및 기술 요구사항 (Design System & Technical Specs)

**1. 컬러 팔레트 (Color Palette)**
| 이름 | 용도 | HEX Code | 비고 |
| :--- | :--- | :--- | :--- |
| **Primary Blue** | 신뢰, 기본 정보, 배경 | `#0A3D62` | Deep Navy (전체적 안정감) |
| **Danger Red** | 손실, 위험, Pain Point | `#B71C1C` | 진한 빨간색 (경고 및 위기 감정 유발) |
| **Success Green** | 절약액, 수익, Solution | `#388E3C` | 생생한 녹색 (성공과 이득 체감) |
| **Neutral White/Grey** | 배경, 텍스트 | `#F5F5F5` / `#333333` | 가독성을 극대화. |

**2. 타이포그래피 (Typography)**
*   **Headline:** Pretendard Bold / Impactful (굵고 힘 있는 느낌)
*   **Body:** Pretendard Regular (가독성 최우선)
*   **숫자 데이터:** Monospace 폰트 또는 고대비의 Sans-serif를 사용하여 '정량적'인 느낌을 강화.

**3. 애니메이션 및 인터랙션 로직 필수 사항**
1.  **전환 속도:** 모든 단계 전환 시, 단순 페이드(Fade)보다 **Parallax 스크롤링 효과와 함께 데이터가 점진적으로 팝업되는 (Staggered Pop-up)** 구조를 채택하여 몰입도를 높인다.
2.  **데이터 변화:** 수치적 변화는 절대 갑자기 바뀌지 않도록, 항상 **부드러운 커브(Easing function: Cubic Bezier)**를 사용하여 애니메이션화한다.
3.  **상태 기반 로직 (Stateful):** 사용자가 A라는 액션을 취해야만 B 단계의 정보가 열리게 설계하여, 모든 정보를 한 번에 주지 않고 '발견하는 재미'와 '필요성 인지'를 동시에 만족시킨다.
